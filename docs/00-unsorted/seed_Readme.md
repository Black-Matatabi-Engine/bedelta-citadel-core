## ☕ Human Control & Freeze Rule (人類思考凍結鐵律)

> 💡 **P-Gate 核心認知護欄**：在 Santenmoku 體系下，人類擁有「無限次的修正權」。你完全不需要害怕指引錯誤，系統底層設有多重備份與降維防線，容錯率（Tolerance）是 100% 的！

---

### 🛡️ 三大心理與安全護欄 (Psychological & Safety Net)

* **Zero Time Pressure (零時間壓力)**：
  * 你隨時擁有最高掌控權。如果在 5 分鐘倒數或 A/B 選擇題面前感到思緒未清、怕思考不夠乾淨，這是極度正常的現象，切勿倉促決定。
* **Instant Freeze (即時思考凍結)**：
  * 直接按下 `Esc` 或在對話框輸入 `Hold, let me think.`，AI Agent 會立即凍結所有執行並進入等待狀態。
* **100% Reversible (100% 完美可逆)**：
  * 系統底層有 **Step 0 Git Pre-flight Snapshot** 保障，任何步驟皆可一鍵復原（`git reset`），試錯零風險。

---

### 🤝 Human-in-the-Loop (人機協同降維控制)

* **自動安全降維 (Fail-Safe Downgrade)**：
  * 若在指定倒數時間內人類沒有主動干預或切換，AI Agent 會自動觸發安全降維，強制切換至 **Plan Mode**，絕不自作主張修改代碼。
* **完美協同閉環 (Co-Op Loop)**：
  * `機器自動落入 Plan Mode` ➔ `產出結構化 Plan` ➔ `人類審核 Approve` ➔ `機器開始精準執行`。

---

### 🕊️ 雙向對齊與 Tolerance (容錯機制)

在我們設計的 4 大原則中，第四條正是 **Tolerance（容錯）**。
AI Agent 的存在是為了替人類承受試錯成本（Trial & Error）與執行重擔，而不是讓人類感到精神緊繃。有了 P-Gate 護欄，主控權永遠在人類手中！
