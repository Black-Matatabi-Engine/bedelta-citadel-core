### 1.3 GMX Live-Fire vs ExoMesh 守衛（安全誠實）

```text
評委以為的路徑:
  Agent intent → ExoMesh soil → Gate consume-once → PolicyGuard → GMX

實際 1300 live-fire:
  CONFIRM_GMX_MICRO_FILL=YES BROADCAST=1
  ALLOW_STALE_ORACLE=1
  BYPASS_SOIL_PROBE=true
  FORCE_EOA_FALLBACK=1
       └─ ExchangeRouter direct（Reader + fee + 5% cap）
```

**結論：** Keeper fill 證明 **GMX 參數對齊**（SC 執行面 ✅）。它**不**證明 ExoMesh 在主網擋過一筆毒意圖。對外若把 `0x2e47f4fe…` 講成「防火牆 live」，屬 **品類謊言**。正確賣法：「我們能把 GMX 開平倉跑完；防火牆 demo 用 `pnpm demo:gmx -- --trip` **不** bypass。」

### 1.4 Variational Zero-Alloc（`evaluateSwapPerpSoilZero`）

熱路徑：無 `new` · 寫入預分配 `SoilResultSlot`。Fail-closed：swap 休市 · carry > 800 bps · quote age · OLP 深度 · perp funding vol > 80 bps。這是 **Inno 真增量**，但公開 `SUBMISSION` 5-Core 表仍把 Variational 當 RFQ adapter 口號，**未引用** `variational-instrument-guard.zero.ts`。

### 1.5 鄰近市場（Q3 · 不是真空）

| 鄰近層 | 做什麼 | 與 ExoMesh 差在哪 |
|--------|--------|-------------------|
| **Blockaid / Blowfish / WC Scan** | 遠端模擬「這筆 tx 鏈上會怎樣」 | 200–800ms · 第三方看見 calldata · **簽署後/簽署時警告**，不是本地 mandate |
| **Fireblocks + embedded agent wallet** | 托管 + 策略引擎 + 審計軌 | 企業採購長 · **不是** EIP-1193 開源 drop-in |
| **ERC-8196 鏈上政策** | 結算期檢查 | **燒 gas** · 擋不住 broadcast 前 |
| **ERC-7715 session keys** | 權限衰減 | 標準有 · **場館土壤（GMX/Pendle/Variational）沒有現成產品** |
| **Maiat / 類似 viem trust-gate** | 信任分 · 反投毒 | 網路聲譽 · **不是** 0-Gas 場館不變量 |

**空檔一句話：** *Mandate + venue soil, in-process, before sign, 0-Gas on reject.* 這句才是可賣的獨特性。**不要**說「市場沒有類似產品」— 買家會拿 Blockaid 對標；你要贏的是 **locus（本地）+ 拒絕成本（0 gas）+ 場館不變量**。
